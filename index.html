这两个“下载”分别是什么意思？我该怎么做？（点击展开）

① 下载 ssq.js（离线版）
是什么：把当前页面里（可能已联网更新过的）最新数据，导出成一个 ssq.js 文件——它就是把数据写进网页的“离线数据包”。
有什么用：本平台默认双击 index.html 离线打开，而浏览器不允许离线页面自己读取本地文件，所以数据必须“内嵌”在这个 ssq.js 里。你每次联网更新后，必须下载它并替换掉项目里原来的 data/ssq.js，下次双击打开才是新数据。
你需要做：点“下载 ssq.js”→ 浏览器把文件存到“下载”文件夹 → 把它移动到项目目录的 data/ 文件夹、覆盖同名旧文件。完成。

② 下载 ssq.json（在线版/备份）
是什么：同样的最新数据，但导出为标准的 ssq.json 格式（数据本身是 JSON）。
有什么用：它是“在线版/备份”文件——将来若把平台发布到 GitHub Pages（需要联网访问），页面会去读取这个 data/ssq.json。同时它也是一份纯数据备份，可单独保存或分享。
你需要做：点“下载 ssq.json”→ 存到“下载”文件夹 → 若用于发布，把它上传/覆盖到仓库的 data/ 文件夹并推送；若仅备份，妥善保存即可。

小结：想在本机双击用 → 用 ssq.js（离线版）；想发布到网上或留一份标准备份 → 用 ssq.json（在线版/备份）。两者内容相同，只是用途与存放位置不同。
