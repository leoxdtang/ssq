# 双色球策略分析平台

一个**纯静态、零依赖**的双色球历史数据分析、统计与策略回测平台。无需后端、无需联网即可在浏览器打开使用；也可一键部署到 GitHub Pages 并自动更新数据。

## 功能

- **数据总览**：最新期号、开奖日期、奖池、数据源、更新时间；展示每一期每个奖项的金额（一/二等奖为浮动，取自数据；三/四/五/六等奖为固定规则金额：¥3000 / ¥200 / ¥10 / ¥5）。
- **统计分析**：可设置「分析窗口大小 W」与「分析时间段」，统计红/蓝球频率、遗漏值、热号/冷号、奇偶比、区间分布、和值、AC 值、连号，以及各奖级平均注数/奖金。
- **策略设置**：内置 6 个常用策略（默认**随机策略**），支持**可视化规则自定义**选号（热/冷/遗漏/综合、奇偶均衡、区间均衡、禁连号、排除号、单式/复式），并可实时预览选号。复式设有**最大投注注数上限**，超过自动裁剪红球数，防止单期成本失控。
- **回测评估**：在历史时间段内滚动回测，统计总投入、总中奖、净收益、**ROI**、命中率、最大回撤、最长连亏、收益曲线与逐期明细（可导出 CSV）。
- **策略对比**：多策略同参数并跑，直观比较 ROI / 净收益 / 命中率。
- **自动更新**：GitHub Actions 定时（每周二/四/日晚开奖后 + 每日兜底）抓取最新一期并提交。

## 本地使用（推荐：直接双击打开）

数据已内嵌为 `data/ssq.js`（全局变量），因此**直接双击 `index.html` 即可离线使用**，无需任何服务器：

```
双击 双色球/index.html  →  浏览器打开
```

> 若你的浏览器对 `file://` 限制较严导致空白，可在目录下起一个静态服务器：
>
> ```bash
> cd 双色球
> python -m http.server 8080      # 然后访问 http://localhost:8080
> ```

## 数据来源与更新

- **当前数据** `data/ssq.json` / `data/ssq.js`：**共 3515 期（2003001 ~ 2026118）**。
  - **2015 ~ 至今**：已用**中彩网官方接口**补全，**含各奖级浮动金额、销量、奖池，完全完整**。
  - **2003 ~ 2014**：开奖号码/日期完整；**少数早期（尤其 2003–2004）一/二等奖浮动金额在权威源中本就缺失**。在你本机运行 `fetch-data.mjs` 时会用开源镜像自动补齐（镜像含完整 2003+ 历史奖金）。
  - **2020 疫情期间**约 53 天无开奖，属**真实历史停摆**，非数据缺失。
- **如何更新 / 补全数据（两种方式）**：
  1. **命令行脚本（推荐，最彻底）**：在本机装好 Node 后运行 `node scripts/fetch-data.mjs`，自动拉官方 2015~至今 + 镜像补早期，并写出 `data/ssq.json` 与 `data/ssq.js`。详见 **`数据更新与运行指南.md`**。
  2. **浏览器内“分批次联网更新（补全缺口）”按钮**（无需账号）：打开页面点该按钮，优先官方接口、失败自动改镜像；随后点「下载 ssq.js（离线版）」覆盖本地文件。注意中彩网官方接口**不允许浏览器跨域**调用，故浏览器内主要靠镜像补全。
- 完整步骤、GitHub Pages 更新方法、数据源探索结论，见 **[`数据更新与运行指南.md`](./数据更新与运行指南.md)**。

## 说明

本平台仅用于历史数据分析与策略回测。双色球开奖完全随机，任何策略都无法预测中奖；所有 ROI 均为历史模拟，不代表未来收益，不构成投注建议。
